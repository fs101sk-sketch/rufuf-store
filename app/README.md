# نظام الأعمال (Business OS)

نظام تشغيل أعمال معياري (Modular Business OS) — Local-first، عربي RTL أولًا.
هذا المجلد مستقل عن متجر "رفوف" الموجود في جذر المستودع ولا يؤثر عليه.

## المتطلبات

- Node.js 20 أو أحدث
- npm

## التشغيل أثناء التطوير

```bash
npm install
npm run dev
```

يفتح على `http://localhost:5173`.

## البناء للإنتاج

```bash
npm run build   # tsc -b && vite build → يُخرج مجلد dist/
npm run preview # لمعاينة نسخة الإنتاج محليًا
```

## الاختبارات

```bash
npm run test        # يشغّل الاختبارات مرة واحدة (vitest run)
npm run test:watch  # وضع المراقبة أثناء التطوير
```

الاختبارات تغطي: تحقق صحة المدخلات، حساب التقدّم من المهام الفعلية،
الفلاتر والفرز، إحصائيات المشاريع، عمليات CRUD الحقيقية عبر IndexedDB
(إنشاء/تعديل/حذف ناعم واستعادة/حذف نهائي متسلسل/تكرار المشروع مع مهامه)،
واستمرار البيانات بعد "إعادة تشغيل" قاعدة البيانات (إغلاق وفتح نسخة جديدة
بنفس الاسم).

## الفحص والتنسيق

```bash
npm run lint  # oxlint
```

## قاعدة البيانات

التطبيق **local-first**: كل البيانات تُخزَّن في IndexedDB داخل المتصفح عبر
[Dexie.js](https://dexie.org)، ولا تُرسل إلى أي خادم. القاعدة اسمها
`business_os`، ويمكن فحصها من أدوات المطور في المتصفح
(Application → IndexedDB → business_os).

المخطط معرّف في `src/core/db/schema.ts` بنظام migrations حقيقي (كل
`.version(n)` هو ترحيل إضافي؛ لا يُعدَّل إصدار بعد نشره، بل تُضاف نسخة
جديدة). الجداول الحالية:

- `workspace` — سجل واحد يمثّل مساحة العمل.
- `settings` — إعدادات مفتاح/قيمة (المظهر، تفضيلات العرض).
- `activity_log` — سجل نشاط لكل عملية مهمة (إنشاء/تعديل/حذف/استعادة).
- `projects` — المشاريع.
- `tasks` — المهام (مرتبطة بمشروع، أو مستقلة).

## النسخ الاحتياطي

من صفحة **الإعدادات** داخل التطبيق:

- **تصدير نسخة احتياطية**: يُنزّل ملف JSON يحتوي على كل البيانات
  (`{ app, version, exportedAt, workspace, settings, projects, tasks }`).
- **استيراد نسخة احتياطية**: يتحقق من صحة الملف (اسم التطبيق، رقم الإصدار،
  وجود الحقول المطلوبة)، يعرض ملخصًا بعدد العناصر قبل التنفيذ، ثم يستورد
  داخل معاملة واحدة (upsert بالمعرّف).

## متغيرات البيئة

لا يحتاج هذا الإصدار (Foundation + Projects) أي متغيرات بيئة أو مفاتيح —
كل شيء محلي. عند إضافة وحدة الذكاء الاصطناعي لاحقًا ستُضاف `.env.example`
توضّح الإعدادات غير السرية فقط (مفاتيح الـ API الفعلية لن تُخزَّن في الكود
أو قاعدة البيانات أو الواجهة الأمامية).

## بنية المجلدات

```
src/
  core/            طبقة الأساس المشتركة بين كل الوحدات
    db/            مخطط Dexie + migrations + bootstrap
    settings/      خدمة الإعدادات + تفضيل المظهر
    activity/      سجل النشاط
    backup/        التصدير/الاستيراد
    ui/            مكوّنات مشتركة (Modal، Toast، Confirm، حالات فارغة/تحميل/خطأ)
    modules.ts     سجلّ الوحدات (ما هو منفَّذ فعليًا مقابل "قريبًا")
  modules/
    projects/      وحدة المشاريع الكاملة (repository → service → hooks → UI)
    settings/      صفحة الإعدادات
  App.tsx, main.tsx
```

الوحدات غير المنفَّذة (CRM، المالية، التقويم، الملفات، الذكاء الاصطناعي،
الوكلاء، سير العمل، الذاكرة، مكتبة الأوامر، الاستخدام) **لا تظهر كصفحات أو
أزرار قابلة للنقر** — فقط كقائمة نصية غير تفاعلية تحت "قريبًا" في الشريط
الجانبي وصفحة الإعدادات، حتى لا يوحي أي عنصر في الواجهة بأنه يعمل قبل أن
يُبنى فعليًا.
