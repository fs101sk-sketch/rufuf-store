# متجر رفوف

متجر عربي للمنتجات الرقمية يعمل على GitHub Pages، مع Supabase لقاعدة
البيانات والمصادقة وحفظ الطلبات. المنتج المنشور حاليًا هو **لعبة المجلس**
بسعر 17 ر.س وسعر عرض 13 ر.س.

## التشغيل

افتح `index.html` مباشرة للعرض المحلي. النسخة المنشورة تحتوي على رابط مشروع
Supabase والمفتاح العام القابل للنشر فقط. لا يوضع مفتاح `service_role` أو أي
مفتاح سري في الواجهة.

## قاعدة البيانات

المخطط الأساسي موجود في `supabase/schema.sql`، وإضافة لعبة المجلس في
`supabase/majlis.sql`، ومخطط الغرف اللحظية في `supabase/majlis-rooms.sql`.
هذه الملفات تفعّل RLS، وتقصر الإدارة على حساب المالك
المصرّح به. بنك الأسئلة يُرفع مباشرة إلى Supabase ولا يُنشر في المستودع
العام حتى لا تظهر الإجابات داخل مصدر الصفحة.

## لعبة المجلس

اللعبة منشورة من المسار `majlis/`. لا يحتوي كودها على كلمة مرور الأدمن.
دخول المالك والعملاء يتم عبر Supabase Auth، وقراءة الأسئلة لا تعمل إلا
لحساب يملك استحقاقًا فعالًا.

بعد انتقال الطلب إلى حالة `paid` تنشئ وظيفة `majlis-access` حساب اللاعب
تلقائيًا، ثم تسمح للمشتري باستلام اسم المستخدم وكلمة المرور باستخدام رمز
طلب عالي العشوائية لا يُخزن كنص مكشوف في قاعدة البيانات.

عند بدء مجلس جديد ينشئ الخادم غرفة برقم من 6 أرقام. يدخل الضيوف بالرقم ثم
يختارون الاسم والأفاتار من دون إنشاء حساب أو إدخال كلمة مرور. قائمة الانتظار
وحالة السؤال والنتيجة والبازر تتزامن بين الأجهزة عبر Supabase Realtime، بينما
تظل جداول الغرف مقفلة عن القراءة المباشرة وتُستخدم من خلال وظائف محددة فقط.

اللعبة مهيأة كتطبيق PWA من المسار `majlis/`، وتشمل ملف Manifest وService
Worker وأيقونات Android وWindows وApple وزر تثبيت داخل الواجهة. ملفات الواجهة
الثابتة فقط هي التي تُخزن للعمل دون اتصال؛ طلبات Supabase لا يلتقطها كاش
التطبيق. حالة الجولة الجارية تُحفظ محليًا لكل مستخدم وتستعاد بعد تحديث الصفحة.

عند تحديث التطبيق يجب رفع إصدار الكاش في `majlis/service-worker.js` من
`majlis-app-cache-v4` إلى الإصدار التالي حتى تُحذف النسخة القديمة بطريقة
منضبطة.

> طريقة الدفع الحالية هي تحويل بنكي مع اعتماد يدوي من لوحة الطلبات. ربط
> بوابة دفع فعلية يحتاج حساب مزود دفع ومفاتيح webhook خاصة به.

## نظام الأعمال (app/)

مجلد `app/` يحتوي مشروعًا منفصلًا تمامًا عن متجر "رفوف": نظام تشغيل أعمال
معياري (Modular Business OS) قيد البناء (Vite + React + TypeScript،
تخزين محلي عبر IndexedDB/Dexie). لا يؤثر على متجر "رفوف" المنشور ولا
يشاركه أي كود أو بيانات. راجع `app/README.md` للتشغيل والتفاصيل، و
`docs/CURRENT_STATE_AUDIT.md` لحالة كل وحدة.
