# متجر رفوف

واجهة متجر عربية ثابتة تعمل على GitHub Pages، مع Supabase لقاعدة البيانات
والمصادقة وحفظ الطلبات.

## التشغيل

افتح `index.html` مباشرة للعرض المحلي. النسخة المنشورة تحتوي على رابط مشروع
Supabase والمفتاح العام القابل للنشر فقط. لا يوضع مفتاح `service_role` أو أي
مفتاح سري في الواجهة.

## قاعدة البيانات

المخطط موجود في `supabase/schema.sql`. وهو يفعّل RLS، ويقصر الإدارة على بريد
المالك المدرج في الجدول الخاص `private.store_admin_emails`.

> بوابات الدفع والشحن في هذه النسخة تجريبية، ولا تنفذ تحصيلًا ماليًا حقيقيًا.
